# Web primitives

Import components directly from their `.tsx` modules. Each owns a CSS module and accepts copy
from its caller; translate labels and messages with `useI18n` in the composing page. Shared
surface, tone, border and shadow tokens live in `../styles/tokens.css`.

| Module                                             | Contract                                                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Button`, `IconButton`                             | Native button props and refs; primary/secondary/toolbar/link, tones, icon, shortcut, loading. Pass `disabled` and `disabledReason` together to expose a focusable reason tooltip while keeping the button inert. `IconButton.active` controls its pressed state.                                                                                                                                                |
| `PageTabs`, `DockTabs`, `Tabs`, `SegmentedControl` | Controlled values; disabled options. Page tabs are navigation buttons; dock/provider tabs use Radix tab panels; segments keep one selection and use roving focus. Dock options accept `count` and `bad`. Page options accept `changed` and `disabledReason`.                                                                                                                                                    |
| `Chip`, `ChipOverflow`                             | Toggle with `pressed`/`onPressedChange`, action with `onClick`, condition with `onRemove`/`removeLabel`; `bad` and `dashed` states. Overflow shows the first `limit` options and opens the complete checkbox list. Callers own rules such as requiring one selected value.                                                                                                                                      |
| `NumberField`                                      | Controlled raw string (a number is accepted as input), `min`/`max`/`step`, optional stepper, compact and read-only states. Arrow keys snap to the min-based grid; PageUp/Down move ten steps. Stepping clamps to bounds and rounds decimal drift; typing preserves empty, partial and invalid drafts for caller validation. Supply translated `label`, `incrementLabel`, `decrementLabel`, `error`, and `hint`. |
| `TextInput`, `FieldRow`                            | Native text/search/date input props. FieldRow's render callback supplies `id`, `aria-describedby`, and `aria-invalid`; spread them onto the control to associate its label, hint and error.                                                                                                                                                                                                                     |
| `Select`, `Combobox`                               | Radix grouped select with typed options. Combobox is a searchable suggestion list with disabled results, arrows, Home/End, Enter, Escape, and active-descendant focus. It filters supplied options locally; fetching results belongs to a workflow.                                                                                                                                                             |
| `Checkbox`, `ToggleSwitch`                         | Radix state and form props, native keyboard behavior, required accessible label. Checkbox supports `indeterminate`.                                                                                                                                                                                                                                                                                             |
| `Popover`, `DropdownMenu`, `Tooltip`, `Dialog`     | Radix portals, collision handling, keyboard dismissal and focus restoration. Triggers must forward props/ref (our buttons and chips do). Dropdown entries can be actions, headings or separators. Dialog accepts title, optional description, close label, body, footer and size. `DialogClose` and `PopoverClose` compose footer actions via `asChild`.                                                        |
| `ToastProvider`, `useToast`, `Toast`               | `push({ message, tone, duration, action })` returns an id for `dismiss(id)`. FIFO queue, 5-second default, timer paused on hover/focus via Radix. Action toasts never time out; the action, Close, Escape or swipe dismisses them. `action.altText` explains the alternative operation to assistive technology. Static `Toast` supports sheet previews.                                                         |
| `Note`, `Banner`, `Tag`                            | Neutral, amber and danger surfaces; tags also have blue. Banners accept a title, body, icon and actions. Callers choose `role="status"`/`"alert"` where announcements are appropriate.                                                                                                                                                                                                                          |
| `ProgressBar`                                      | Omit `value` for indeterminate progress; determinate values clamp to `[0, max]`. Pass a translated label and optional value text. Respects reduced motion.                                                                                                                                                                                                                                                      |
| `SectionHeading`, `KeyValueRow`, `EmptyState`      | Presentational title/action, label/value, and title/body/actions compositions. Empty-state title is 15px/600.                                                                                                                                                                                                                                                                                                   |
| `Table`                                            | Semantic table children, optional caption, plain or leaderboard style and compact rows. `data-selected="true"` marks a leaderboard row. Scrolling is contained in a focusable region; use a real button for row actions. No virtualization or sorting rules.                                                                                                                                                    |
| `Icon`                                             | Every icon from `gen/ui.mjs`, plus minus. Typed `name`, `size`, SVG props, and optional `label`; unlabeled icons are decorative. `iconNames` enumerates the set.                                                                                                                                                                                                                                                |

The close controls in dialogs and toasts intentionally omit their redundant tooltip so one Escape
closes the surface. Native disabled controls retain disabled semantics; their reason wrapper is
the keyboard stop. Components never parse package errors or make workflow decisions.

Run behavior tests with `npm run test --workspace @pine/web`. The dev sheet and browser checks are
documented in [../sheet/README.md](../sheet/README.md).
